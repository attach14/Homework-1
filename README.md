# Homework 1 — параллельный quicksort

Я реализовал последовательную и параллельную версии быстрой сортировки на C++. Обе выбирают опорный элемент как медиану из первого, среднего и последнего элементов. В параллельной версии разбиение массива выполняется последовательно, а две полученные части сортируются параллельно через `parlay::par_do`.

Для сравнения я провёл пять запусков на случайных массивах по $10^8$ элементов. В каждом запуске обе версии получали копии одного массива. Измерялось только время сортировки. После каждого запуска я проверял, что массив упорядочен. Замеры сделаны до упрощения кода выбора медианы трёх.

| Версия | Число потоков | Среднее время |
|---|---:|---:|
| Последовательная | 1 | 7,36 с |
| Параллельная | 4 | 2,28 с |

По пяти запускам параллельная версия оказалась в **3,23 раза быстрее**. Ускорение ниже четырёхкратного в том числе потому, что первое разбиение всего массива выполняется в одном потоке.

Для случайного массива ожидаемая сложность последовательного quicksort — $O(n \log n)$. При $n = 10^8$ получаем $n \log_2 n \approx 2{,}66 \cdot 10^9$. Если для грубой оценки принять скорость $5 \cdot 10^8$ простых операций в секунду, получится около **5,3 секунды**. Реальное время зависит от числа сравнений, обменов и обращений к памяти, поэтому это оценка по порядку величины. Полученные **7,36 секунды** с ней согласуются.

## Как запустить

Для сборки нужен `clang++` с поддержкой C++17. Папка `parlaylib/` с заголовками библиотеки должна лежать рядом с `quicksort.cpp`. Обе команды выполняются из этой папки проекта.

Сборка программы:

```bash
clang++ -std=c++17 -O2 -pthread -Iparlaylib/include quicksort.cpp -o quicksort
```

Запуск с четырьмя рабочими потоками для параллельной версии:

```bash
PARLAY_NUM_THREADS=4 ./quicksort
```

Программа выполняет пять прогонов и выводит время каждой сортировки, средние времена и ускорение.
